# Foldinto · 贴会儿

**把想留住的内容贴下来，以后再慢慢看。**

Foldinto 是一个正在开放共创的收藏与回看工具。我们会逐步开放适合社区参与的部分，并在每个仓库说明开放范围和许可证。

👉 [打开 Foldinto](https://foldinto.com/)

## 它适合什么人？

如果你经常收藏文章、视频、图片或随手记下的想法，却不容易在以后重新找到它们，欢迎来试试 Foldinto。把感兴趣的内容放进自己的桌面，写下当时的想法，再通过分类、搜索和日历回看。

## 和我们一起共创

你不需要会写代码。我们很想听到你真实的使用体验：

- **试用与交流**：在 Discussions 分享你保存内容和回看的习惯，或提出产品想法。
- **报告问题**：在 Issues 描述遇到的问题和复现步骤，帮助我们定位。
- **参与设计与建设**：在讨论中分享建议；后续开放适合贡献的内容时，我们会说明具体方式。

反馈前请移除截图、链接和日志中的个人内容、账号信息和密钥。公开讨论任何人都可以看到。

## 接下来关注什么

目前我们希望先听懂大家如何使用网站，持续改善收藏、找回和回看的体验。社区里的想法会公开讨论，但进入讨论不代表功能已经决定开发或承诺上线时间。

## 开放范围与使用许可

这是产品社区仓库。正式网站的服务器配置、密钥、用户数据和部分实现不会在此公开。未来若开放代码，会逐项说明范围、依赖与适用许可；目前请不要将本仓库理解为完整网站源码或默认获得代码使用许可。

Foldinto 名称、标识和第三方素材的使用权以各自的权利说明为准。
